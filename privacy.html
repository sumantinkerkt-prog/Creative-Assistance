Privacy

Your work stays with you

No account, no server

There is nothing to sign up for. Creative Assistance is a set of plain web pages — there is no database behind it and no server that receives what you type.

Where your projects and notes live

Everything you create — projects, tasks, notes, your checklist, timer settings and saved colour palettes — is stored by your own web browser, on the device you are using. It is never sent anywhere, and nobody else can see it.

Two things to keep in mind. Clearing your browsing data will also remove this work, and it will not appear on your other devices. The home page has a Save a backup button that writes a single file you can keep, or restore on another device.

Analytics and cookies

There is no analytics, no advertising and no tracking of any kind. No cookies are set. The only outside request the pages make is for the Inter typeface from Google Fonts, which is used purely to display text.

Hosting

The pages are delivered by Vercel, which — like any web host — records standard server request information. That is entirely separate from anything you create here.
